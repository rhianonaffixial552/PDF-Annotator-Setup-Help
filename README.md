## ❓ Troubleshooting common errors
Installation often fails due to simple software conflicts. Use these tips to resolve typical issues.

### Setup fails silently
If the installer finishes but you see no icon, check your Start menu. Search for "PDF Annotator" in the taskbar. Right-click the result and choose "Pin to taskbar" for easier access.

### Visual C++ Redistributable errors
Some installations require updated system components. If you receive an error about missing libraries, visit the official Microsoft website and download the latest Visual C++ Redistributable package for Windows. Restart your computer after you install this package.

### Permissions issues
Windows 11 restricts software from modifying system files. If the installation stops halfway, ensure you sign out of other user accounts on your PC. Only one user should use the system during the installation process.

### Antivirus interference
Security software may mistake the installer for a threat. Temporarily turn off your third-party antivirus for ten minutes. Restart the installation. Remember to turn your security software back on once you finish.

6.  Select the new application from the list.
7.  Click Set Default to confirm your choice.
